# 路线图与已知限制

> 状态：**现行** · 最后更新：2026-11-10

## 1. 已知限制（当前版本就有）

| 限制 | 影响 | 备注 |
| --- | --- | --- |
| 只适配澎湃 OS 3 设置的类名 | 换 ROM / 大版本可能部分失效 | 全部 `findClassIfExists` + 日志，不会崩 |
| 平板 / 分屏未适配 | 宽屏下卡片宽度、搜索栏位置可能不理想 | 没做 `sw600dp` 断点 |
| 首页映射靠资源 id 名 | 系统改 id 名后需要补 `SLOT_IDS` | 有标题兜底 |
| 无自动化测试 | 回归靠真机清单 | 见 [安装 · 检查清单](04-install.md#4-首次使用检查清单) |
| 源码与 14.8 发布包不一致 | 14.8 重编包签名不同，无法覆盖；15.0 起 `dist/` 与源码同源 | 见 [状态](00-status.md#已知问题) |
| 液态玻璃 / 开关 / 顶栏模糊 / 专注模式 / 相机 / 搜索入口已上机验证（15.5） | 仍缺：120Hz 慢动作、分屏/平板、深浅色中间帧、第三方主题图标包 | 2026-11-10 真机：相机行在「外观」下方、搜索行在「墙纸」下方，点击分别进入相机设置/搜索设置；专注模式行位于「屏幕时间」上方；主题飞行图标生效、搜索栏保留原生胶囊且浅色无阴影；16.2 顶栏模糊改为 0–100%，16.3 默认 5%，旧 0→300 已过时 |
| 16.0 条件卡片 / 搜索过渡已在**同源测试包**上机 | 正式包（新包名）还没在真机装过 | 测试包验证：iCloud 行、更新卡+角标、耳机卡（REDMI Buds 8 Pro）、点击跳转、搜索进出场动画；正式包只差包名 |
| 16.1 已验证 | 正式包（`com.Remo.ilayoutsettings` 16.1）已覆盖安装并真机实测 | 耳机卡即时刷新（AudioDeviceCallback）、点击进 `MiuiHeadsetActivity` 详情页、退出搜索无两个搜索栏、二级页返回底部栏不消失 |
| 16.2 已验证 | 正式包（`com.Remo.ilayoutsettings` 16.2）已覆盖安装并真机实测 | 指定耳机/iCloud 图标、顶栏透明度 45% + 模糊 30%（淡磨砂）、折叠栏发丝线、搜索栏 19/12/0.1dp、构建自动清 dist |
| 16.3 已验证 | 正式包（`com.Remo.ilayoutsettings` 16.3）已覆盖安装并真机实测 | 顶栏默认 5% 模糊 / 2% 透明度（近乎全透明）、深色发丝线改中性灰 30%（实拍 (58,58,59)）、浅色仍是黑 12%、`pm clear` 后默认值复验 |
| 16.4 已验证 | 正式包（`com.Remo.ilayoutsettings` 16.4）已覆盖安装并真机实测 | 设置内切深浅色后发丝线不消失（类钩子 + 每帧取色，实拍深 (58,58,59) / 浅 (222,222,223)）、首次折叠前预写模糊半径、GUI 高级设置总开关（关时隐藏顶栏/分割线选项）、新蓝紫玻璃图标 |
| 16.0 改包名 | 旧模块必须卸载、LSPosed 要重新启用 | 见 [安装 · 16.0 迁移](04-install.md#2-160-迁移从-15x-升级才需要) |
| 无 CI | 发版靠本地构建 | 构建脚本已可参数化，适合接 Actions |

## 2. 待办（按优先级）

### P0 — 发版可信度

- [x] **自动发版**：`tools/release.ps1`（构建 → 校验 → tag → Release → 上传），v16.0 起每次发版一条命令；
- [x] 用新包名完成 16.1 / 16.2 / 16.3 / 16.4 真机验证（安装 + LSPosed 启用），见会话记录 `2026-11-10-headset-card-live-and-search-exit.md`、`2026-11-10-icons-topbar-opacity-and-release-cleanup.md`、`2026-11-10-topbar-clear-and-dark-divider.md`、`2026-11-10-topbar-hairline-advanced-icon.md`；
- [x] 明确「发布包来自哪个 commit」：16.2 起 `release.ps1` 先自动 commit/push 再打 tag；v16.2 tag 指向包含 dist APK 的提交；
- [ ] 清理 `Hook` 未引用的遗留类（`GlassToggle` / `IntroCard` / `AboutIos` / `AboutExtras` / `TitleFix` / `TitleOverlay` / `PrefsBridge`）与 `BottomSearch` 里的 lattice 反射分支；
- [ ] 清理后对比 dex 体积，确认与发布包量级一致。

### P1 — 质量与协作

- [ ] GitHub Actions：`tag push` 触发构建 + 上传 APK + 生成 Release（需要 android-36 platform 与 build-tools，可用 docker 镜像）；
- [ ] Issue 模板（bug / feature）+ 反馈清单（已有 [模板](08-troubleshooting.md#10-反馈模板)）；
- [ ] 真机回归清单固化成 `docs/04-install.md` 的 checklist（已有初版）；
- [ ] 平板适配：`sw600dp` 下搜索栏宽度上限、卡片左右留白。

### P2 — 能力

- [ ] 首页 slot 映射可配置（不改代码也能调整顺序）；
- [ ] 二级页图标继续扩充（覆盖更多设置页）；
- [ ] 深色模式/主题切换后的自动重排与发丝线对比度实拍（目前靠重进页面）；
- [ ] 顶栏模糊 / 透明度做 2~3 个预设（淡磨砂、更透、更实），减少两个滑杆的试错。

## 3. 明确不做

- 自绘整个设置界面（违背「不重绘」原则，维护成本无上限）；
- 接管搜索逻辑；
- 搬 smali / 打包第三方反编译代码进 dex（15.x 已证明不可维护，见 [设计思路](05-design-notes.md) 2.7 节）；
- 支持非 MIUI/HyperOS 的 ROM。

## 4. 怎么提新需求

1. 先确认需求落在「重排 / 注入 / 显隐」范围内；
2. 在 Issue 里写清：目标页面、期望效果、参考图、机型与系统版本；
3. 实现后按 [agent.md](../agent.md) 记录设计取舍与踩坑。
